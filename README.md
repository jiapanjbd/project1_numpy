在仓库根目录执行：

```bash
python numpy_homework.py          # 依次运行 12 道题，打印全部中间量与结果
```

## 设计说明

1. **shape 先行**：所有函数在入口处用 `ndim` / `shape` 校验输入，在注释与报告中固定“输入 shape → 输出 shape”链路，避免广播意外的降维或升维。
2. **零循环向量化**：E7、M1、M3、M4 均以一条矩阵/广播表达式完成，M3 用 `A[:,None,:] - B[None,:,:]` 构造 `(M,N,D)` 差数组，避免双重循环。
3. **数值安全**：`arccos` 之前统一 `np.clip(cos, -1, 1)`，防止浮点误差（如 `1.0000000000000002`）导致 `nan`；零向量按题意区分处理——`angle_deg` / `unit_vector` / 查询向量抛 `ValueError`，`angles_to` / `top_k_cosine` 的零向量行返回 `nan` 或被排除。
4. **不修改输入**：`unit_vector` 用除法生成新数组，E1 用 `A.copy()` 后再做掩码赋值，M4 不改动给定参数。
